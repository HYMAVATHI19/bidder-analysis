# Bidder analysis - python

A simple Python project that collects bids from multiple bidders and determines the winner with the highest bid.

## Features

* Accepts multiple bidders
* Stores bidder names and bids in a Python dictionary
* Finds the highest bid
* Displays the winning bidder and bid amount

## Concepts Practiced

* Dictionaries
* `while` loops
* `for` loops
* `if` statements
* Functions
* User input
* `.lower()` method

## How to Run

Make sure Python is installed on your computer.

Run:

```bash
python bidder analysis.py
```

## Example

```text
Enter your name: Alex
Enter your bid: 500
Are there more bidders? yes/no: yes

Enter your name: Sam
Enter your bid: 750
Are there more bidders? yes/no: no

Winner is Sam with a bid of 750
```
